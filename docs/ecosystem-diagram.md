# Outer Void ecosystem map

This page previously showed a diagram of five repositories that never existed (`blux-core`, `blux-orbit`,
`blux-design-system`, `blux-experience-kit`, `blux-governance`). That content was removed on 2026-10-26; it is
still in this repository's git history.

The maintained ecosystem map is in the central documentation repository:

- [Ecosystem map, authority boundaries, and when to use `blux` vs `ax`](https://github.com/Outer-Void/docs/blob/main/ecosystem/README.md)
- [Component status matrix](https://github.com/Outer-Void/docs/blob/main/ecosystem/status-matrix.md)

In short:
- **BLUX** is the intelligence and integration platform, and `blux` is its direct CLI.
- **AXIOM** (`ax`) is the developer control plane. It routes to the authoritative engines: blux10k, GOD,
  BLUX, CogA, cA, LRC, DAT, BLUX System and VoidForge.
- The **products** stand alone: AXIOM Launcher with VOID.SYS and AXIOM Shooter, VoidForge, Roughin, Vigyl,
  and Resolver with its website.
