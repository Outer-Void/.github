# Contributing

These defaults apply to every Outer-Void repository that has no `CONTRIBUTING.md` of its own.

- **Licensing.** Outer-Void code is proprietary by default (see each repository's `LICENSE`). Contributions are
  accepted only from authorized Outer-Void members, or with written permission from the owner.
- **Where things are decided.** Roles, boundaries and cross-repository policies are in the
  [ecosystem constitution](https://github.com/Outer-Void/docs/blob/main/constitution/README.md). A change that
  crosses a repository boundary is checked against it first.
- **Evidence.** A pull request states what changed, how it was tested (commands and results), and what was not
  tested. Do not describe unfinished work as done.
- **Attribution.** Third-party code, assets and AI assistance are attributed in
  [Outer-Void/credits](https://github.com/Outer-Void/credits). Licence texts are never edited.
- **Never commit** credentials, keystores, personal data or private paths.
- **Security issues** go to [SECURITY.md](SECURITY.md), not to public issues.
